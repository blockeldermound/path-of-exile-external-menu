## 🧩 About

**Path of Exile desktop helper** is a curated list of Path of Exile open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap viewer, stash browser
- **Quality-of-Life Helpers** — item filter manager, loot tracker, overlay notes
- **Research Notes** — passive tree layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Minimap Overlay — enlarged map view with waypoint markers
- Loot Tracker — log dropped currency and gear for review
- Item Filter Manager — swap and edit filters in-game
- Timers — track flask and buff durations for study

### 🎨 Catalog & Build Notes
- Passive Tree Notes — organize build paths and ascendancy plans
- Stash Browser — search stash tabs from an overlay
- Gem Catalog — browse skill gems and supports

### 🏋️ Practice Layout
- Damage Log — review incoming and outgoing hits
- Resist Planner — visualize capped resistance targets
- Boss Mechanics Notes — study encounter phases and timings
